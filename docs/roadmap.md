# Roadmap

## Phase 0 — foundation
- [x] Dedicated GitHub repository identified and initialized.
- [ ] Core contracts, schema and CI validation committed.
- [ ] Dedicated Supabase project provisioned.
- [ ] Migration and RLS tests pass in staging.

## Phase 1 — identity and device foundation
- Supabase Auth, profile lifecycle and device registration.
- App catalogue, installation records and notification inbox.
- User data export and deletion foundations.

## Phase 2 — connector framework
- OAuth callback service, encrypted token storage and revocation.
- Provider capability registry and synchronization cursors.
- First connectors selected by API availability and user value.

## Phase 3 — first user applications
- Player profile and game library with explicitly sourced data.
- Notifications, calendar, notes and device dashboard.
- Web portal and Kode Dot client read models.

## Phase 4 — expansion
- Additional gaming platforms, Home Assistant, GitHub and media integrations.
- Offline sync, observability, reliability and performance work.

A phase is complete only when code, automated tests and deployment evidence exist. A connector is not marked available based only on a design or OAuth login.
